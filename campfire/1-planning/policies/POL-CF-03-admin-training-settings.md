# POL-CF-03 — 어드민: 훈련 강의실 링크 · 클래스챗 설정 정책

## 용어

- **훈련(Training)** = 어드민에서 생성·관리하는 KDT 과정 단위(부트캠프 기수).
- **강의실 링크** = 수강생이 라이브 강의에 입장하는 경로 설정. 타입을 라디오로 선택한다.
- **라이브룸** = 기존 라이브 강의실.
- **클래스챗** = 채팅 공간(RocketChat 기반). 사용 여부 + 링크로 구성.
- **Campfire** = 채팅 + 라이브 강의를 통합 제공하는 자체 플랫폼(`POL-CF-02` 참조).

## 의도

기존 클래스챗·라이브룸은 **DB 설정값에 의존**해 동작했으나, 어드민에서 그 값을 설정할 UI가
부족했다 — 특히 **클래스챗은 사용 여부 boolean과 링크 컬럼이 DB에만 존재하고 어드민 설정 구좌가 전혀 없었다.**

Campfire 도입에 맞춰 **훈련 단위로 (1) 강의실 링크 타입과 (2) 클래스챗 사용 여부·링크를
어드민에서 직접 설정**할 수 있도록 구좌를 신설한다. 또한 **훈련 생성 시 캠프파이어 클래스를 자동 생성**해,
이후 강의실 링크에서 캠프파이어를 곧바로 연결할 수 있게 한다.

> 본 정책은 **어드민 설정(공급자 측)** 을 정의한다. 설정 결과가 수강생에게 어떻게 노출되는지는 `POL-CF-02`.

## 정책

### 1. 강의실 링크 — 타입에 "캠프파이어" 추가

1. **위치**: 어드민 접속 → `훈련` → `훈련관리` 탭 → **KDT 훈련 정보** 메뉴 → **강의실 링크** 항목.
2. **타입 선택(라디오)**: 기존 **`라이브룸` · `링크`** 2종 → **`라이브룸` · `링크` · `캠프파이어`** 3종으로 확장(캠프파이어 신규 추가).
3. **타입은 단일 선택**한다(하나의 훈련은 한 타입만).
4. **신규 생성되는 훈련은 모두 기본 타입을 `캠프파이어`로 설정**한다(훈련 생성 시 캠프파이어 클래스 자동 생성과 연동 — `§3`). 운영자가 필요 시 다른 타입으로 변경할 수 있다.
5. 타입별 동작:

   | 타입 | 링크 입력 | 수강생 입장 경로 |
   |---|---|---|
   | `라이브룸` | 불필요 | (현행) 라이브룸 강의실 |
   | `링크` | **필수**(외부 URL) | (현행) 입력한 외부 링크 |
   | `캠프파이어` (신규) | **불필요**(자동 연결) | 훈련 생성 시 자동 생성된 **캠프파이어 클래스**(`§3`) |

### 2. 클래스챗 관리 (신규 항목)

1. **위치**: **강의실 링크 항목 하단**에 `클래스챗 관리` 항목을 신규 추가한다.
2. **사용 여부(라디오)**: `미사용` · `사용` → DB의 **클래스챗 사용 여부 boolean**과 매핑.
3. **클래스챗 링크 입력 구좌** → DB의 **클래스챗 링크 컬럼**과 매핑. (기존 DB 컬럼을 그대로 사용하고, 어드민 구좌만 신설)
4. **활성/비활성 규칙**:
   - **`사용` 선택 시 → 링크 입력 구좌 활성화**(입력 가능, 필수).
   - **`미사용` 선택 시 → 링크 입력 구좌 비활성화**(입력 불가·회색 처리).

   | 사용 여부 | 링크 입력 구좌 | DB 매핑 |
   |---|---|---|
   | `미사용` | 비활성화 | boolean = false |
   | `사용` | 활성화(필수) | boolean = true · link = 입력값 |

5. **기본값 = `미사용`**(신규 훈련). 기존 훈련은 DB 현재값을 표시한다.
6. **`강의실 링크`가 `캠프파이어`인 경우, 클래스챗 관리는 자동으로 `미사용`으로 설정**한다 — **항목은 화면에 그대로 표시**(숨기지 않음)하고 링크 입력만 비활성화한다. 캠프파이어가 채팅을 포함하므로 중복을 방지하되, 운영자가 필요 시 **수동으로 `사용` 전환은 가능**하다.

### 3. 설정 시점 · 캠프파이어 클래스 자동 생성

1. **위 모든 설정(강의실 링크 타입 · 클래스챗 관리)은 훈련이 생성된 이후에만 설정**할 수 있다. 훈련 생성 폼에는 포함하지 않는다.
2. **훈련 생성 시 캠프파이어 클래스를 자동 생성**한다(생성 시점에 캠프파이어 공간/클래스를 자동 프로비저닝).
   - 이후 `강의실 링크`에서 `캠프파이어` 선택 시 별도 입력 없이 이 클래스에 연결된다.
3. **적용 범위 = 본 정책 적용 이후 신규 생성되는 훈련에 한한다.** 기존 훈련에 대한 **마이그레이션은 수행하지 않으며**, 기존 훈련은 현행 설정값을 그대로 유지한다.

## 설정 매트릭스 (한눈에)

| 항목 | 위치 | 입력 형태 | 값 | 비고 |
|---|---|---|---|---|
| 강의실 링크 | KDT 훈련 정보 | 라디오 | 라이브룸 / 링크 / **캠프파이어** | 캠프파이어 신규, 단일 선택 |
| └ 링크 입력 | 강의실 링크 하위 | 텍스트(URL) | `링크` 타입일 때만 필수 | 라이브룸·캠프파이어는 불필요 |
| 클래스챗 관리 | 강의실 링크 **하단**(신규) | 라디오 | 미사용 / 사용 | DB boolean 매핑 |
| └ 클래스챗 링크 | 클래스챗 관리 하위(신규) | 텍스트 | `사용`일 때만 활성·필수 | `미사용` 시 비활성화 |
| 캠프파이어 클래스 | (자동) | — | 훈련 생성 시 자동 생성 | 어드민 입력 없음 |

> 설정 가능 시점: **훈련 생성 이후**. 훈련 생성 시점에는 캠프파이어 클래스 자동 생성만 수행.

## 예외 처리

각 예외는 **[유저(운영자) 영향]**과 **[UX/시스템 해결안]**을 함께 정의한다.

| 케이스 | 영향 | 해결안 |
|---|---|---|
| 클래스챗 `사용` 선택 후 **링크 미입력 저장** | 빈 링크로 노출 → 수강생 입장 불가 | 저장 시 **필수 검증** + 인라인 에러 "클래스챗 링크를 입력해주세요" |
| 클래스챗 `사용` → `미사용` 전환 | 입력했던 링크 값 손실 우려 | 링크 값은 **보존**(비활성화·숨김만), `사용` 재선택 시 복원 |
| 강의실 링크 `링크` 선택인데 **URL 미입력/형식 오류** | 입장 불가 | URL 형식 검증 + 인라인 에러("올바른 링크를 입력해주세요") |
| 훈련 생성 시 **캠프파이어 클래스 자동 생성 실패**(외부 연동 오류) | 캠프파이어 타입 선택/입장 불가 | 실패 시 **자동 재시도** + 어드민 알림, **수동 재생성** 액션 제공 |
| **기존 운영 중 훈련**(설정 구좌 없던 시절 생성) | 신규 정책 미적용 | **마이그레이션하지 않음** — 기존 훈련은 현행 설정값 유지(`§3-3`). 본 정책은 신규 훈련부터 적용 |
| 강의실 링크 `캠프파이어` 선택 | 별도 클래스챗과 채팅 공간 중복 우려 | 캠프파이어 선택 시 클래스챗 **자동 `미사용`**(항목은 표시 · 운영자 수동 `사용` 전환 가능) — `§2-6` |
| 설정 저장 **중복 클릭** | 중복 요청·경합 | 저장 버튼 클릭 직후 로딩 처리로 다중 요청 차단 |

## 비정책 (의도적으로 정하지 않음 / 확인 필요)

- ~~강의실 링크 = `캠프파이어`일 때 클래스챗 관리 동작~~ → **확정**: 캠프파이어 선택 시 클래스챗 자동 `미사용`(항목은 표시, 운영자 수동 전환 가능)(`§2-6`).
- ~~클래스챗 관리 기본값~~ → **확정**: 신규 훈련 `미사용`, 기존 훈련은 DB 현재값(`§2-5`).
- ~~강의실 링크 기본 타입~~ → **확정**: 신규 훈련은 모두 `캠프파이어` 기본(`§1-4`).
- ~~기존 훈련 마이그레이션~~ → **확정**: 수행하지 않음, 신규 훈련부터 적용(`§3-3`).
- 캠프파이어 클래스 자동 생성 실패 시 재시도 횟수·간격 등 상세는 **백엔드 spec 위임**.
