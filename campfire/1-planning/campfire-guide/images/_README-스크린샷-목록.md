> 알림 설정 변경(전체 메시지 옵션 삭제 + 클래스별 알림 신설) · 출석 캡쳐/녹화/QR 조회가 **클래스 모니터링**으로 통합 ·
> 채널 만들기 2단계 위저드화 · 연동 봇 `설정 > 연동` 분리 · 투표/그룹/멤버 진단/활동 리포트/배경 효과/저사양 모드 신규.

> **강의 입장 화면은 2종**
> • 내가 여는 경우 — “강의를 열고 참여합니다”. 장치 드롭다운 없음, **마이크·카메라 모두 꺼짐**

> **개인정보 주의**: 캡쳐 모니터링·QR 조회·강의 입장/설정 이미지는 얼굴·실명 영역에 블러를 적용해 제작했습니다.
