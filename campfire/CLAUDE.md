# campfire/CLAUDE.md

Campfire 팀 작업 시 AI가 따를 컨텍스트. `shared/CLAUDE.md` 를 먼저 읽었다고 가정한다.

## 팀 정의

- **프로덕트**: Campfire — 통합 교육 플랫폼 (운영진·수강생 daily hub)
- **주 사용자**: P2 Operator > P1 Trainee
- **핵심 가치**: 운영 효율 + 수강생 engagement

## 이 팀에서 자주 쓰는 단어 (요약)

상세는 `campfire/3-backend/glossary.yml`. 새 용어는 거기에 추가한 뒤 본문에서 사용.

- `Squad` — 한 Cohort 안의 소그룹 (5~7명)
- `Daily Check-in` — 매일 오전 출석 + 컨디션 체크 의식

## 작업 가드레일

1. Operator UX 결정 시 P2 페르소나 우선.
2. `Daily Check-in` 같은 의식(ritual) 관련 정책 변경은 PRD frontmatter `impact: ritual` 표기.
3. Classroom과 공유되는 개념은 `shared/glossary.yml`로 올리고 양 팀 동시 PR.
