## 개요

- 대상 기능: 재평가 등록(신규/수정) 화면 '평가 시험' 선택 시 노출되는 선택 모달([문항 불러오기] / [불러오지 않고 직접 작성] / 취소·닫기=롤백)을 통한 원본 평가 문항 불러오기. 자동 불러오기(선택 즉시 무조건 로딩)는 폐기됐다(사용자 확정 정책, SSOT v1.5 반영 완료). 덮어쓰기 확인 모달은 별도 모달이 아니라 이 선택 모달에 통합되며, 기존 문항이 있으면 삭제 경고가 병기된다. 능력명·평가 제목은 [문항 불러오기]·[불러오지 않고 직접 작성] 어느 쪽을 선택해도 자동 입력되며(평가 제목은 원본 값 그대로 편집 가능한 초안으로 채워짐 — 능력명과 동일 규칙, 접두 자동 부여 없음), [취소/닫기] 선택 시에만 제외(미수행, 기존 값 변경 없음)된다.
- 근거 문서(SSOT): `2026-08-03_훈련평가-재평가-문항-불러오기-기획서.md` (v1.7 확인 완료). v1.5에서 FR-001(자동 로딩 폐기 → 선택 모달), FR-004(능력명 자동 입력 조건 보강), FR-005(덮어쓰기 모달을 FR-001 선택 모달에 통합), FR-006(빈 상태도 동일 모달 노출)의 FR 번호는 유지되고 조항 내용만 개정됐다. v1.7에서 FR-004에 평가 제목이 복사 대상으로 추가됐다(원본 값 그대로 복사, 최대 20자 제한 공유로 초과 불가, 접두 미부여 — 재평가 목록 구분은 평가 타입 값으로 해소).
- 본 카탈로그는 SSOT §6에 이미 등재된 기본 엣지케이스(문항 0개 원본, 선택 모달 삭제 경고 병기, 빈 상태 동일 모달 노출, [직접 작성] 선택 시 능력명·평가 제목 자동 입력, [취소/닫기] 선택 시 롤백, 필수값 누락 문항, 저장 전 이탈, 저장된 재평가 원본 변경 2건, 조회 실패, 연타, 원본 사후 삭제 — v1.7 갱신본 기준)은 재나열하지 않는다. 해당 항목은 SSOT §6을 참조한다. 본 문서는 동시성, 경계값, 상태 경합, 권한 변동, 네트워크/부분 실패, 원본 데이터 이상, 선택 모달 정책(v1.5~v1.7) 관점에서 §6이 다루지 않은 케이스만 확장한다.
- 화면은 SC-201(재평가 등록/수정 화면) 단일 화면 — 상세는 화면정의서 참조. 요소 단위 세부(SC-201-01~10)는 화면정의서 소관이며 본 문서는 EC별 관련 FR만 표기한다.
- SSOT 정책과 모순되는 기대 동작은 제시하지 않았다. "기대 동작" 열에 스펙 근거가 없는 항목은 제안이며, 확정 전까지 상태를 "정의 필요"로 표기한다.
- 본 카탈로그는 인수기준·테스트케이스 본문, 결함 등록을 다루지 않는다. 해당 산출물은 별도 QA 문서 소관이다.

복사 범위 확정(v1.4·v1.7) — 문항 전체 + 능력명 + 평가 제목 복사(제목·능력명은 원본 그대로 편집 가능한 초안, 취소 시 미수행), 평가기간·대상자만 신규 입력 — 관련 검토: 평가 제목 복사 포함(v1.7)에 따라 EC-019의 "재평가 제목은 신규 입력" 전제 문구를 정정하고(EC-019는 이제 드롭다운 표시 트렁케이션만 다룸), EC-029에 평가 제목 동일 규칙을 반영했다(SSOT FR-004 실제 문구로 확정, "SSOT 반영(v1.7) 종결"). 능력명 마스터 변경·삭제 상태에서의 복사값 처리는 기존 카탈로그에 없는 신규 관점이나, 금번 지시가 "관련 EC 기대 동작·상태만 갱신"으로 한정돼 신규 EC 추가는 보류한다.

v1.5 정책 개정(선택 모달 전환) 반영 — 자동 로드·구 덮어쓰기 모달 전제의 트리거 표현("원본 선택 즉시 조회")을 "[문항 불러오기] 선택 후 조회"로 그룹 1(EC-001~004)·그룹 2(EC-005·006)·EC-007·EC-025·EC-026에서 정합화했다. 그룹 2 표제를 "선택 모달 통합(FR-005·FR-006)"으로 갱신했다(FR 번호는 SSOT v1.5에서도 유지, 조항 내용만 개정). 신규 시나리오 3건(EC-027~029)을 그룹 11로 추가했다.

v1.6 검수 후속 반영 — 동일 원본 재선택 시 선택 모달 재노출이 확정되어 EC-027을 "SSOT 반영(v1.6)"으로 갱신, 취소 시 능력명 값 변경 없음(자동 입력 미수행·수동 수정분 유지)이 확정되어 EC-029를 "SSOT 반영(v1.5) 종결"로 정리, 0건 원본 선택 시 선택 모달의 [문항 불러오기] 비활성이 확정되어 EC-018 기대 동작에 모달 단계 예방 동작을 정합화(상태 "SSOT 반영(v1.4·v1.6)"). EC-007 버전 분류는 표 스펙 근거 열(SSOT FR-010, v1.4에서 확정된 문구)과 요약 문단을 v1.4로 통일해 일치를 재확인했다.

v1.7 검수 후속 반영 — 평가 제목도 복사 대상 포함(원본 그대로 편집 가능, 능력명과 동일 규칙, 취소 시 미수행)이 SSOT v1.7 FR-004 본문(changelog 포함)으로 확인·반영됐다. EC-029의 기대 동작·스펙 근거를 FR-004 실제 문구로 교체하고 상태를 "SSOT 반영(v1.7) 종결"로 확정했다. 신규 검토 2건을 그룹 12로 추가·종결 처리했다 — 원본 제목 글자수 경계(EC-030, SSOT FR-004 "평가 제목은 원본 값 그대로 복사한다(원본도 최대 20자 제한이므로 초과 없음)" 문구로 확정), 동일 제목 재평가 목록 혼동(EC-031, SSOT FR-004 "재평가 목록 구분은 평가 타입 값(평가/재평가)으로 이미 해소되기 때문" 문구로 확정) — 두 건 모두 무리한 신규 리스크 발굴 대신 SSOT 확정 근거 인용으로 종결했다. EC-019의 "재평가 제목=신규 입력" 전제 문구가 v1.7 정책과 상충해 정정했다.

SSOT §9 미결 사항 중 이번 결정으로 해소된 항목은 3건(FR-007 문항 0개 하한, FR-010 응시 이력 "진행 중" 포함 여부, FR-004 복사 제외 필드 범위)이다. 나머지 §9 미결 사항(§3 노출 범위 구체값, FR-009 사후 삭제 표시, 임시저장 여부 전제, §8 개별 문항 편집 정책 확인)은 계속 미결이며, 본 카탈로그의 해당 미결 전제에 종속된 항목(예: EC-002, EC-021)은 "정의 필요" 상태를 유지한다.

- SSOT 정책 수정(§9 미결 사항 확정)은 담당 범위 밖이며, 본 문서는 보고만 한다.
