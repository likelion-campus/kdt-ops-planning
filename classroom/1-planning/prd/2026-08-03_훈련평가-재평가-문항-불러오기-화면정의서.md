## [검토 기준]

- 출처: 기능정의서(SSOT) `2026-08-03_훈련평가-재평가-문항-불러오기-기획서.md` v1.5(검수 통과본) FR-001~FR-011, §4.1 재평가 상태별 허용 여부, §4.2 문제 유형별 복사 대상 필드, §5 유저 플로우. 기존 화면 구조는 평가 등록 화면(상단 평가 제목·능력명·평가기간, 우측 평가 상세 패널 — 평가 타입 드롭다운·평가 시험·대상자, 문항 카드 편집기)을 전제로 한다.
- 가정: 이 문서에 명시하지 않은 화면 요소·레이아웃·워딩은 기존 화면 구조를 그대로 유지하며 재설계하지 않는다. 선택 모달·안내·에러 문구의 최종 워딩은 화면 설계 영역으로 위임한다(SSOT §10 준용).
- 검증 기준: 모든 SC 요소가 SSOT FR-ID에 매핑되어 있는지, 자동 불러오기 폐기 후 조회·로딩·실패·차단·연타 트리거가 "선택 모달 진행" 시점으로 일관되게 서술되는지, 잔여 미결은 [확인 필요]로 유지되는지, 기존 화면 구조를 벗어난 신규 요소가 없는지.

## 대상 화면·진입점

### SC-201 재평가 등록/수정 화면 (기존 화면, 평가 유형 = 재평가)

이번 델타는 신규 화면을 만들지 않는다. 기존 평가 등록 화면에서 평가 타입을 '재평가'로 선택했을 때 노출되는 기존 UI(평가 시험 드롭다운, 대상자, 문항 편집기)에 불러오기 선택 모달·차단 동작만 추가한다.

| 구분 | 내용 |
|------|------|
| 진입 경로(신규) | 평가 등록 화면 진입 → 평가 상세 패널에서 평가 타입 = '재평가' 선택 (기존 기능, 변경 없음) |
| 진입 경로(수정) | 평가 목록에서 저장된 재평가 항목 클릭 → 재평가 수정 화면 진입 (기존 기능, 변경 없음) |
| 이탈 경로 | ① [저장하기] 성공 → 평가 목록으로 이동 ② [취소]/뒤로가기 → 평가 목록으로 이동. 저장 전 이탈 시 불러온 문항은 소실되며 재진입 시 처음부터 다시 진행해야 함(전제: 기존 화면에 임시저장 없음 — [확인 필요], SSOT §9) ③ FR-010 차단 시 "신규 재평가 생성" 안내 텍스트 노출까지가 본 문서 소관이며, 이를 링크·버튼으로 연결해 재평가 등록 화면(신규)으로 이동시킬지 여부는 화면 설계 영역 [확인 필요] |
| 변경 없는 요소 | 평가 제목·평가 시작일~종료일 입력, 대상자 선택, [미리보기] 버튼, 문항 카드의 기존 편집 기능(질문 번호, 보조 설명, 문제 유형, 보기 입력·정답 선택·보기 추가, 주관식 정답 입력, 해설, 배점, 삭제, 드래그 정렬) |

## 상태별 화면 분기

SSOT §4.1(재평가 상태별 문항 불러오기 허용 여부)을 화면 요소 단위로 매핑한다.

| 재평가 상태 | '평가 시험' 필드 상태 | 문항 불러오기 | 문항 교체(원본 재선택) | 관련 SC 요소 |
|-------------|------------------------|---------------|--------------------------|--------------|
| 신규 등록(저장 전) | 선택 가능 | 허용 — 선택 시 선택 모달 노출(문항 미존재 시 대체 경고 없음 SC-201-04, 문항 존재 시 대체 경고 병기 SC-201-03). [문항 불러오기] 클릭 시에만 조회 실행 | 허용 | SC-201-01, 03, 04, 06 |
| 저장됨 · 평가기간 시작 전(응시 이력 없음) | 선택 가능 | 허용. 0건 저장 불허(FR-007 확정)로 저장된 재평가는 항상 문항 1개 이상 → 선택 모달에 대체 경고 병기(SC-201-03) | 허용(선택 모달에서 [문항 불러오기] 선택) | SC-201-01, 03, 06 |
| 저장됨 · 평가기간 진행 중(제출 0건) | 비활성(disabled) | 차단(선택 모달 자체가 노출되지 않음) | 차단(선택 모달 자체가 노출되지 않음) | SC-201-10 |
| 저장됨 · 응시 이력 1건 이상 존재 | 비활성(disabled) | 차단(선택 모달 자체가 노출되지 않음) | 차단(선택 모달 자체가 노출되지 않음) | SC-201-10 |

공통 사항: 선택 모달 노출(SC-201-03·04), 로딩 표시(SC-201-02), 연타 처리(SC-201-07), 조회 실패 롤백(SC-201-08), 저장 시점 검증(SC-201-09)은 위 표에서 '불러오기·교체가 허용된 상태' 전반에 공통 적용되며, 상태별로 별도 분기하지 않는다.
