## 대상 화면·진입점

### SC-101 어드민 적합성 검사 문항 설정 (기존 화면)
| 구분 | 내용 |
|------|------|
| 진입 경로 | 훈련 관리 → 교육 관리 → 적합성 검사 탭 (기존, 변경 없음) |
| 이탈 경로 | [저장하기] 성공 → 저장 완료 토스트. 저장 전 이탈 시 미저장 변경 소실(기존 화면 정책 준용) |
| 변경 없는 요소 | 검사 ON/OFF 토글, 문항 유형(단일/복수/선형/주관식) 추가·삭제·드래그 정렬, 질문·보기·선형 라벨 입력 등 기존 편집 기능 |

### SC-102 어드민 조회·노출 (지원자 목록·상세, 지원서 엑셀)
| 구분 | 내용 |
|------|------|
| 진입 경로 | 지원서 관리 → 지원자 목록 / 지원자 상세(지원서 보기) / 엑셀 다운로드 (기존, 변경 없음) |
| 변경 없는 요소 | 지원서 응답 원문·과제·합불 상태 처리 등 기존 지원자 상세 구성 |

| 요소 ID | 노출 조건 | 상태 | 액션 | 결과 | 예외 | 대응 FR |
|---------|-----------|------|------|------|------|---------|
| SC-101-01 | 채점 적용(`scoring_enabled = true`) 검사 · 문항 미잠금 | 전 유형 문항에 **배점 입력 필드**(숫자 + `점` suffix, 필수 `*`) 노출 | 배점 값 입력(1 이상 정수) | 문항 배점 확정, 상단 합계 배너에 반영 | 잠금 시 disabled(SC-101-05). 미적용 검사는 미노출(SC-101-06) | FR-001 |
| SC-101-02 | SC-101-01 조건 · 문항 유형 = 객관식 단일선택 | 보기별 **`정답` 라디오** 노출(항상 1개 선택 유지 — 기본 선택). 복수선택·선형·주관식은 정답 UI 없음 | 정답으로 지정할 보기의 라디오 선택 | 문항 정답 확정(채점 기준, FR-005) | 라디오 기본 선택 유지로 "정답 미지정" 상태는 UI상 발생하지 않음(별도 에러 상태 없음) | FR-002 |
| SC-101-03 | 채점 적용 검사 문항 설정 진입 시 상시 | 상단 **`현재합계 / 100점` 배너** 노출 | 배점 입력에 따라 실시간 갱신 | 합계 100 아니면 저장 불가 안내 유지 | — | FR-003 |
| SC-101-04 | [저장하기] 또는 검사 ON 전환 시 검증 실패 | 미입력·무효 필드 **red 강조 + 저장 버튼 disabled**. ① 질문·보기 미입력 red ② **배점 `0`(미입력) red**(질문·보기와 동일 톤) ③ 배점 합계 배너 `N/100` | 사용자 재입력 후 재저장 | 검증 통과 시 저장(저장 완료 토스트). 0문항 ON 시 "생성된 질문이 없습니다" 안내 | 검증은 저장·ON 전환 시점에만(문항 단위 저장 아님) | FR-003, FR-014 |
| SC-101-05 | 해당 검사에 지원자 1명 이상 존재(지원 취소·불합격 포함, SSOT §8-7) | **배점·정답 필드 disabled**(회색), 문항 추가 차단(채점 적용 검사만). **제목만 수정 가능** | 배점·정답·문항 추가 불가 | 지원자 발생 후 배점·정답 변경 원천 차단(영구 0점 방지) | 지원자 수 0명 복귀 시 해제(경로는 SSOT 범위 밖) | FR-004 |
| SC-101-06 | 채점 미적용(`scoring_enabled = false`) 검사 | **배점·정답 입력 UI 자체 미노출**(기존 문항 설정 화면과 동일). 별도 안내 배지·툴팁 두지 않음 | 기존 문항 편집만 | 배점·정답 개념 없음, 채점·총점 미산출 | 미적용 안내는 시스템 UI 대신 운영 안내로 갈음(SSOT §7·§9) | FR-015 |

## 상태별 화면 분기 (SC-101 배점·정답 편집 가능 여부)

| 검사 상태 | 배점·정답 필드 | 문항 추가 | 관련 요소 |
|-----------|----------------|-----------|-----------|
| 채점 적용(true) · 지원자 0명 | 입력 가능 | 가능 | SC-101-01·02·03·04 |
| 채점 적용(true) · 지원자 1명 이상 | **disabled(잠금)** · 제목만 수정 | **차단** | SC-101-05 |
| 미적용(false) | **UI 미노출** | 기존대로 가능 | SC-101-06 |

## 확인 필요 사항

SSOT §8 잔여 확인 사항 중 화면에 영향을 주는 항목만 인용한다(이 문서에서 임의 확정하지 않는다).

| 항목 | 영향 요소 | 근거 |
|------|-----------|------|
| 검사 응시 화면 문항별 필수/선택(스킵 가능 여부), 선형배율 초기 선택값 | (응시 화면 — 본 델타 밖) | SSOT §8-8 |
| 지원 취소 철회 시 총점 표기 복귀 규칙 | SC-102-01·02·03 | SSOT §8-10 |
| 어드민 지원자 상세의 문항별 획득 점수 표기 여부 | SC-102-02 | SSOT §9 |
| 안내·에러·공란 문구 최종 워딩 | SC-101-04, SC-102-03 | SSOT §9, 화면 설계 위임 |
