## 0. 의도

학생은 **"하루 일과 학습판"**을, 매니저는 **"현황 진단판"**을 갖는다.
정책은 **합의가 끝난 규칙**만 담는다. 합의 진행 중 항목은 PRD `§11 변경 이력`에서 추적한다.

## 1. 권한 (클래스룸 내 학생 / 매니저 2종)

> **범위 주의**: 본 권한은 **클래스룸 도메인 한정**이다.
> 캠프파이어 · Admin 도메인은 별도로 **4종 권한(학생 · 강사 · 퍼실 · 매니저)**으로 분리 운영한다 — 채널·운영 정책이 다르기 때문.

1. **클래스룸 내 권한은 학생 / 매니저 2종**으로만 운영한다.
2. **클래스룸의 매니저 권한 1종**을 강사 · 퍼실 · 운영담당자가 동일하게 공유한다 (역할별 분리 권한은 두지 않음).
3. **캠프파이어 · Admin 권한 = 학생 / 강사 / 퍼실 / 매니저 4종**으로 별도 운영한다. 클래스룸의 "매니저"는 캠프파이어·Admin 상에서는 본인의 직책(강사·퍼실·매니저) 권한으로 분리되어 동작한다.
4. 분반·강의별 필터링은 권한이 아닌 사용자별 자체 적용으로 처리한다.
5. **권한 = 데이터 접근 범위**, **시나리오 = 메뉴별 실제 동작**으로 분리해 정의한다 (메뉴별 매트릭스는 PRD §6).
6. 클래스룸 LNB는 학생·매니저 공통 고정 구조를 사용하며, 우상단 토글로 학생뷰 / 매니저뷰를 전환한다.

## 2. AI 퀴즈 — 자동 발행

1. 문항은 **객관식 10문제**만 발행한다. OX·단답형은 도입하지 않는다.
2. AI 노트 기반 Draft는 **전일(D) 14:00 자동 생성**한다.
3. 학생 발행 시각의 **default 는 09:10**, 매니저가 회차별로 변경할 수 있다.
4. **휴일은 자동 발행하지 않으며, 다음 수업일로 자동 이월**한다.
5. **00시 기준 하루 1회만 자동 발행**한다. 자동 재시도는 하지 않는다.
6. 자동 발행 실패 시 **매니저가 수동으로 발행**할 수 있다.
7. Draft 단계에서는 매니저가 문항·선지·정답·해설을 자유 편집하고, **재생성 트리거**를 사용할 수 있다.
8. **발행 이후에는 텍스트(문항·해설)만 수정 가능**하며, **정답·보기 번호는 잠금**된다.
9. 학생 응시는 **1회만 허용**한다. 재진입 시 즉시 결과 페이지를 노출한다.

## 3. AI 퀴즈 — 오답노트 · 보충 퀴즈

### 3.1 오답노트

1. **오답노트는 별도 메뉴를 두지 않고 `AI 퀴즈` 메뉴 안 탭으로만 존재**한다.
2. **오답 자가 등록은 불가**하다. 오답은 퀴즈 응시 결과로만 자동 누적된다.
3. 오답노트는 **날짜별 문제 리스트**로 표시한다. 카드 클릭 시 그날 틀린 문제 세부 화면으로 진입한다.
4. 문제 세부 화면은 **객관식 전체 문제 + 본인이 선택한 보기 + 정답 + 해설을 한 번에** 표시한다.
5. 오답노트에서 제공하는 학생 액션은 **`메모 추가` · `책갈피` 두 가지**다.
6. **오답을 다시 푼다고 해서 정답으로 전환되지 않는다** — 한 번 누적된 오답은 그대로 보존된다 (복습 기록 보호).
7. **오답노트는 매니저뷰에 노출하지 않는다** — 학생 자기학습 영역으로 보호한다.

### 3.2 보충 퀴즈

1. 보충 퀴즈는 **오답노트와 분리된 별도 탭**에서 학생이 직접 생성해 푸는 형태다. 오답노트 내부에서 직접 푸는 액션은 두지 않는다.
2. 보충 퀴즈는 **학생이 직접 생성**한다 (날짜·오답중심·문제 수 옵션).
3. **별도의 상시 한도는 두지 않는다**. 단 어뷰징 방지를 위해 **학생 1인 하루 최대 100문제까지** 생성 가능하다.
4. 하루 100문제 한도를 초과해 생성을 시도하면 인라인 에러를 노출한다 — **"오늘 한도를 넘었습니다"**.
5. **매니저는 보충 퀴즈를 생성·발행하지 않는다**. 매니저뷰에서는 학생별·날짜별 사용수 히트맵 통계만 확인할 수 있다 (하루 10건이 가장 붉은 색).
6. 보충 퀴즈는 **별도 결과 영역**에 누적된다. 오답노트(`§3.1`)의 정답 상태에 영향을 주지 않는다.

## 4. 실습

1. 메뉴명은 **`실습`**으로 통일한다. `AI 실습` 표기는 사용하지 않는다.
2. **AI 자동 생성·자동 채점은 도입하지 않는다**. 강사가 직접 등록한 실습 문제만 노출한다.
3. **하루에 여러 실습 문제 발행이 가능**하다 (날짜별 리스트 → 그날 문제 리스트).
4. **제출 마감 시간을 두지 않는다**. 결과를 내지 못한 실습도 이후에 다시 제출할 수 있다.
5. 학생 제출 항목 — **텍스트 필수**, 파일·이미지·URL은 선택.
6. 매니저 채점은 **점수·코멘트 모두 옵션**이다. 채점하지 않은 제출은 학생 화면에서 `-`로 표시한다.
7. **매니저에게 채점 의무·리마인더를 두지 않는다**. 제출 유무 자동 집계만 표시한다.
8. 매니저 채점 뷰는 **학생×문제 표**로 구성한다 (제출자 색상 / 미제출 회색).
9. 매니저는 실습 발행 시 **캠프파이어 공지 옵션**으로 채널·메시지를 함께 등록할 수 있다.
10. 발행 후 매니저는 **텍스트만 수정 가능**하며, 수정 시 최근 수정 시간과 학생 카드에 `수정됨` 배지를 노출한다.

## 5. TIL

1. 페이지명은 **`나의 TIL`**, 부제는 "매일 배운점을 정리해보세요"로 표기한다.
2. 작성 폼은 **마크다운 본문 단일 에디터**로 구성한다. 빈 본문에는 템플릿 placeholder를 자동 삽입한다 — `# 오늘 배운것` · `# 막힌것` · `# 내일 할 것`.
3. 작성 폼 우측에 **오늘의 컨텍스트 3종(AI 노트 · 오답노트 · 실습)을 읽기 전용**으로 노출한다.
4. 작성 중 **자동 저장** — `임시` 상태로 진입한다.
5. `게시하기` 시 **`작성` 상태로 전환**하고 히트맵을 즉시 갱신한다.
6. **게시 이후에도 자유 수정이 가능**하다. 게시일 잠금을 두지 않는다. 최근 수정 시각만 로그로 남긴다.
7. 본인 페이지에는 **활동 기록 히트맵 + 작성 카드 리스트**를 노출한다 (3색: 미작성·임시·작성).
8. 매니저뷰는 **학생×날짜 히트맵**(3색 + 범례)으로 표시하며, **셀 클릭 시 본문 슬라이드 패널**을 연다.
9. **위험군 별도 라벨을 두지 않는다** — 히트맵 회색으로 자연스럽게 식별한다.
10. 마크다운 복사 시 **메타데이터를 포함하지 않고 본문만 복사**한다.

## 6. 프로젝트

1. 운영 회차는 **기초 · 심화 · 파이널** (기본 3종) + **`기타 프로젝트`** (매니저 선택)로 구성한다.
2. 각 회차는 **제출 기간 + 피드백 기간을 분리**해 설정한다.
3. 회차 등록 필수 항목 — **제목 · 설명 · 프로젝트 URL · 발표자료 · 시연 영상 URL**.
4. 학생 제출은 **회차당 1건**으로 제한한다. **마감 전까지는 수정 가능**하다.
5. 제출 폼 필수 항목 — 제목 · 한 줄 소개 · 설명(마크다운) · 메인 이미지 · 프로젝트 URL(다중) · 시연 영상 URL.
6. 시연 영상 URL은 **YouTube / Vimeo만 허용**한다.
7. **제출 후 해당 수업 내 게시판에 자동 공개**된다 — 다른 학생의 제출물을 열람할 수 있다.
8. **피드백(매니저 코멘트)은 본인만 확인 가능**하다 — 다른 학생에게 노출하지 않는다.
9. **외부 발행은 기본 OFF**다. 학생이 명시적으로 `발행` 토글을 ON 해야 외부 발행 링크가 생성된다.
10. 외부 발행 URL은 권한 검사 후 노출하며, **비공개 전환 시 즉시 차단**한다.
11. 매니저는 모더레이션 권한으로 `비공개 전환` · `우수 프로젝트 마크`를 사용할 수 있다.

## 7. 알림 (4채널 고정) 

1. 알림은 아래 **4채널 중 하나로만** 발송한다. 인앱 인박스·토스트는 사용하지 않는다.
   - **캠프파이어 "운영 알림"** — 학생 + 강사 + 퍼실 + 매니저 (해당 수업 전체) · 학습 일정/발행 공지
   - **캠프파이어 "매니저 알림"** — 강사 + 퍼실 + 매니저 · 운영 신호(미작성·미응시 등)
   - **학생 개별 DM (캠프파이어)** — 학생 개인 · 본인 호출·결과 알림
   - **슬랙 "live-class-alert"** — 매니저 · 수업명/운영 이슈 내부 공지

> **권한 표기 주의**: 위 채널의 수신 대상은 **캠프파이어 도메인 권한(학생/강사/퍼실/매니저 4종)** 기준이다. 클래스룸 도메인 권한(학생/매니저 2종)과 다른 구분이다 (`§1` 참조).
2. **자동 발송과 매니저 능동 트리거를 구분**한다 (이벤트별 매트릭스는 PRD §8.1).
3. **퀴즈 미응시 알림은 자동 발송하지 않는다**. 매니저가 `미응시자 퀴즈 알림 보내기` 버튼을 눌러야 학생 DM으로 발송한다.
4. **보충 퀴즈 발행 알림은 발송하지 않는다** (학생이 직접 생성).
5. 실습 채점 완료 알림은 **채점된 경우에만 학생 DM**으로 발송한다 (이번 스펙아웃)
6. TIL **3일 연속 미작성** 시 캠프파이어 매니저 알림을 발송한다.
7. 프로젝트 외부 발행 ON 시 슬랙 `live-class-alert`에 추가 알림을 발송한다.
8. AI 노트 생성 실패는 슬랙 `live-class-alert`로만 알린다 (학생 노출 X).
9. 매니저는 본인이 수신할 알림 채널을 4종 중 선택할 수 있다. 기본값은 캠프파이어 매니저 알림.

## 8. 첨부파일

1. **이미지·파일 1건당 30MB까지** 첨부 가능하다 (실습 · 프로젝트 공통).
2. 시연 영상은 **YouTube / Vimeo URL만** 등록 가능하다.
3. 첨부 URL은 형식 검증(스킴·도메인)을 통과해야 한다.
4. 용량 초과 시 표준 문구: **"이미지·파일은 30MB까지 첨부 가능해요"**.
5. URL 형식 오류 시 인라인 에러: **"잘못된 URL 입니다"** 또는 도메인별 안내(`"YouTube 또는 Vimeo 링크만 등록 가능해요"`).
6. 프로젝트 메인 이미지 용량 초과 시 **자동 리사이즈를 시도**하고, 실패 시 에러로 처리한다.

## 9. 본 라운드 범위 외 (비정책)

- **마이페이지 통합 위젯 — 별도로 제공하지 않는다**. 향후에도 본 정책 범위 내에서는 만들지 않는다.
- **팀 프로젝트 별도 처리 X** — 팀 단위 제출 기능을 두지 않고, **팀 프로젝트라도 학생 개개인이 모두 제출**한다 (§6 프로젝트 정책 4번 "회차당 1건" 그대로 적용).
- 인앱 인박스/토스트, 이메일·SMS 알림.
- 외부 발행 도메인 커스터마이즈.
- 다른 학생 TIL 공개 열람, peer review(동료 평가).
- 위험군 별도 라벨/임계치 (Admin 대시보드 고도화에서 진행 예정).
- 매니저 채점 의무·기한 (운영 정책 별도 검토).
