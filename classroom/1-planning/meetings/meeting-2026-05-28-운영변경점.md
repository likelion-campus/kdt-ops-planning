# 클래스룸 운영 변경점 검토 회의 (2026-05-28)

> **목적**: 클래스룸 v2 운영 흐름의 변경점 확정 + 추가 기능 요청 검토.
> **결정 영향 범위**: AI 퀴즈 운영 시간·강사 진단 뷰·자작 퀴즈 / 실습 메뉴 폐지 + Alex 통합 / 신규 요청 5건 분류 (반영·이관·제외·보류).

---

## 1. AI 퀴즈 — 운영 변경

### 1.1 시간 구성 변경

| 시간 | 구성 | 책임 |
|---|---|---|
| **08:30** | 퀴즈 발행 (자동) | 시스템 |
| 08:30 안내 | 매니저가 학생에게 직접 안내 (자동 알림 없음) | 매니저 |
| **08:30 ~ 09:30** | 학생 퀴즈 풀이 | 학생 |
| **09:30 ~ 09:50** | 강사 리뷰 — 모든 퀴즈 함께 풀이 (우선순위는 강사가 판단) | 강사 |

> 변경 전: 09:10 발행 (자동), 매니저 능동 트리거로 미응시자 DM.
> 변경 후: **08:30 발행** + 매니저 능동 안내 + **09:30~09:50 강사 리뷰 슬롯** 신설.

### 1.2 강사 진단 뷰 (필수)

강사가 09:30 리뷰 진입 직전에 다음 데이터를 한 화면에서 확인할 수 있어야 한다:

1. **응시 현황**
   - 누가 풀었는지 / 안 풀었는지
   - 학생별 정답 수 (n / 10)
2. **문항별 오답률**
   - 가장 많이 틀린 문항 식별 → 강사가 리뷰 우선순위 판단 근거로 활용
   - 학생 전체의 이해도 진단
3. **객관식 보기 선택 분포**
   - 각 문항에서 어떤 보기를 가장 많이 선택했는지 (보기별 카운트)
   - 오답이 한 보기에 쏠려 있는지 / 분산되어 있는지 판단

> 시사점: 기존 매니저 "퀴즈 현황 탭"(응시율·정답률·미응시자 + 점수 히트맵)에 **문항별 오답률 + 보기 선택 분포**가 추가로 필요. 강사뷰 / 매니저뷰 일부 데이터 공유 가능.

### 1.3 발행 후 수정 정책 (재확정)

- 발행은 08:30 (자동) — 발행 이후
- **문제 텍스트·해설 텍스트만 수정 가능**
- **정답·보기 번호는 잠금** (변경 불가)

> PRD v1.2.1 정책 그대로 유지. 발행 시각만 09:10 → 08:30 변경.

### 1.4 신규 — 자작 퀴즈 등록 기능

강사가 자동 생성 퀴즈 외에 **직접 문제를 작성**할 수 있어야 한다.

- 문항 유형: **객관식만** (PRD §9 정책 유지)
- 필수 입력: **문제 본문 · 객관식 보기 · 정답 · 해설**
- 자동 생성 Draft와 동일 흐름으로 발행
- 자동 생성 + 자작 혼합 발행이 가능한지(예: 자동 7문항 + 자작 3문항)는 별도 검토

> **PRD 변경 필요**: §4.2 AI 퀴즈 (C) 매니저 시나리오에 "자작 퀴즈 등록" 액션 추가.

## 2. 실습 — 메뉴 폐지 + 자율 운영 전환

### 2.1 별도 실습 메뉴 폐지

- 클래스룸 LNB의 "실습" 메뉴 **삭제**
- 별도 발행·채점 흐름 **제거**
- 학생이 제출 압박 없이 스스로 학습할 수 있는 **여유 공간** 확보가 의도

### 2.2 강의장 + AI 노트 통합

- 강의실에서 실습 관련 내용을 강의로 다룸
- 강의 중 다룬 실습 내용은 **AI 노트에 자동 추가**되는 형태로 통합 (의견 — 추가 검토)

### 2.3 Alex 통합 — 실습 학습 도구

- 실습 시 학생은 **Alex(AXP 어시스턴트)** 를 활용해 학습
- 진입점 UX 개선 필요 — 옵션:
  - **옵션 A**: 강의장 메뉴 하단에 Alex 진입 버튼
  - **옵션 B**: 우상단 별도 아이콘 (전역 진입)
- 결정 보류 — 디자이너 검수 시 옵션 비교 필요

> **PRD 변경 필요**:
> - §2 LNB 구조에서 "실습" 제거
> - §4.3 실습 섹션 전체 제거 또는 "AI 노트 통합 학습" 으로 대체
> - 권한 매트릭스(§6) 실습 행 제거
> - 알림 매트릭스(§8.1) 실습 발행 / 실습 채점 항목 제거
> - 빈상태 카탈로그(§10) 실습 관련 문구 제거
> - **프로토타입**(`1-planning/prototype/`)에서 `practice.html` 삭제 또는 ai-note.html 흡수
