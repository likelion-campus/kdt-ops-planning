## 1. AI 퀴즈

### 1.1 보충 퀴즈 생성 — 옵션 디테일

| 항목 | 디테일 |
|---|---|
| **기본값** | **최근 5일 오답 중심**으로 문제 자동 구성 (학생이 수동 옵션을 선택하지 않으면 기본 적용) |
| **날짜 선택** | **최대 5개 날짜** 다중 선택 가능 (5개 초과 시 disabled · 안내) |
| **하루 생성 제한** | **하루 10회 (세트 단위)** — 초과 시 "오늘 쉬세요" 안내 ("오늘 한도를 넘었습니다" 대신 친근한 톤) |

> 변경 전: 하루 100문제 → 내부 1000문제(미표시) → 신규: **하루 10회(세트)** 표시.
> 의도: 세트 단위 제한이 더 자연스러움. 학생이 한도 가까이 갔을 때 적극적으로 쉬도록 유도.

### 1.2 매니저뷰 보충 퀴즈 히트맵 — 의미 변경

| 항목 | 디테일 |
|---|---|
| **집계 기준** | **학생이 보충 퀴즈를 푼 날짜 기준** (기존: 생성 시각) |
| **최댓값(가장 붉음)** | **10개(=10회)** Max — 1.1 한도와 일치 |

> 매니저는 "이 학생이 어느 날 얼마나 보충을 풀었나"를 보고, 푼 날 기준으로 학습 강도를 진단.

### 1.3 퀴즈 수정 표시 (신규 컨셉)

- 발행 후 매니저가 텍스트를 수정하면 학생뷰에 **`수정됨 · YYYY-MM-DD HH:mm`** 배지 노출
- AI 노트의 "수정됨" 패턴과 동일 톤
- 적용 대상: AI 퀴즈 본문 / 보기 / 해설 (정답·보기 번호는 잠금 유지)
- 응시 완료 학생도 결과 화면에서 수정 표시 확인 가능

### 1.4 단일 재발행 UI (신규 — 우선순위 검토)

- **퀴즈 1개(세트 1개 또는 문항 1개)** 만 재발행하는 경우 대응
- 시나리오:
  - (a) 자동 생성 세트가 오류 → 그 세트만 재생성·재발행
  - (b) 발행 후 정답 오류 발견 → 해당 문항만 정정·재발행 (학생 응시 결과 영향도 정책 필요)
- UI:
  - 세트 카드 우상단 `재발행` 액션
  - 문항 카드 우상단 `이 문항만 재발행`
- 백엔드 영향: 응시 데이터 invalidation·재집계 정책 필요 → PRD v1.3에서 명세

## 2. TIL

### 2.1 발행 후 외부 공유

- 게시된 TIL에 **외부 복사** 액션(공개 URL 생성·복사) + **PDF 다운로드** 액션 추가
- AI 노트의 외부 액션(`마크다운 복사` / `PDF 다운로드`) 패턴 재사용
- 비공개 기본값 유지 — 학생이 명시적으로 외부 복사 시에만 공개 URL 생성

### 2.2 주말 표시

- 활동 기록 히트맵을 **평일 5일 → 주 7일(월~일)** 로 확장
- 주말은 별도 패턴(점선 보더 또는 옅은 회색)으로 "비학습일" 시각화
- 학생이 자율적으로 주말에 작성한 TIL도 표시

### 2.3 날짜 셀렉트

- 작성하기 진입 시 **날짜 셀렉트** 우선 노출 (멋사 `lk-select` 사용)
- 정책:
  - 해당 날짜에 TIL 없음 → **새 글 작성** 모드
  - 해당 날짜에 TIL 있음 → **수정** 모드
- 셀렉트 옵션에는 날짜 + 작성 상태(`작성됨` / `임시` / `미작성`) 함께 표시
- 우수 TIL은 `🏆` 같은 식별자 옵션 우측

### 2.4 우수 TIL 체크 (매니저)

- 매니저가 학생 TIL에 **우수 TIL** 마크 가능
- 학생 히트맵에서 우수 TIL 셀은 다른 시각 처리 — 예:
  - 일반 작성 = 오렌지 풀
  - 우수 = 오렌지 + 별/왕관 아이콘 오버레이 또는 진한 보더
- 색약 대응 — 색 + 아이콘 동시 사용

## 3. 프로젝트

### 3.1 외부 발행 메뉴 제거

- 프로젝트 제출 폼의 **`외부 발행` 토글 제거**
- 외부 공유는 제출 후 `제출 프로젝트 리스트` → 본인 제출본 클릭 → `외부 공유하기` 다이얼로그 (이미 구현)에서만 처리
- 폼에서 토글 추가하면 워크플로 분기가 늘어남 — 단순화

### 3.2 PRD 영향

- §4.5 (B) 폼 구성에서 `발행` 토글 행 삭제
- §4.5 (D) 액션·반응·상태표에서 `발행 토글 ON` 행 삭제
- §9 정책 확정에서 "외부 발행 기본값 OFF" 행은 외부 공유 다이얼로그 정책으로 변경
